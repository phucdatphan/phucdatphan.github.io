# phucdatphan.github.io

Personal portfolio of **Phan Phuc Dat** — IT Business Analyst, Digital Transformation & FinTech System Architecture.

Live site: **https://phucdatphan.github.io**

## Architecture

- **`config/portfolio.config.js`** — Centralized configuration for identity, navigation, case-study dossiers (`EN` / `VI`), field notes (`EN` / `VI`), and stack catalog.
- **`css/styles.css`** — Editorial paper-and-ink design system with light/dark theme tokens, `Be Vietnam Pro` / `Lora` / `JetBrains Mono` typography, smooth page transitions, reading progress bar, and scroll-reveal choreography.
- **`js/site.js`** — Zero-dependency client shell renderer for shared header/footer, persistent theme & language switching, interactive category filtering, and copyable code blocks.
- **Pages:** `index.html` (`About`), `practice.html` (`Practice`), `works.html` (`Works`), `dossier.html` (`System Dossier`), `notes.html` (`Field Notes`), `note.html` (`Note Reader`), and `stack.html` (`Stack`).
